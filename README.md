# Нічний Дозор — Tower Defense (Unity)

## Механіки (з random.org)

| # | Механіка | Реалізація |
|---|----------|------------|
| **21** | Стартовий вибір | 3 раси на старті |
| **4** | Менеджмент армії | Найм, виділення, переміщення, апгрейд юнітів |
| **11** | Захист цілі | Кристал у центрі, вороги йдуть до нього |

## Правило 3×3×3

- 3 раси · 3 типи юнітів · 3 рівні апгрейду
- 3 рівні кампанії · 3 хвилі · 3 типи ворогів

## Керування (курсор)

1. Обрати расу в меню
2. Обрати тип юніта (Воїн / Лучник / Танк)
3. Клік по **слоту** — найняти в армію
4. Клік по **юніту** — виділити
5. Клік по **землі** — наказ руху
6. **Апгрейд** — покращити виділеного юніта
7. **Почати хвилю** — атака ворогів

## Запуск

Відкрийте Unity → Play (або **Night Watch → Setup Game Scene**)
